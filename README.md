# Anbazhagan Selvam — Portfolio

Premium 3D Visualiser & Product Designer portfolio website.

## Structure

```
portfolio/
├── index.html          # Main HTML file
├── assets/             # All images and videos
│   ├── *.jpg           # Project images (4K)
│   ├── *.png           # Screenshots and renders
│   └── *.mp4           # Project videos
├── netlify.toml        # Netlify configuration
└── README.md
```

## Deploy

1. Push this folder to GitHub
2. Connect repo to Netlify
3. No build command needed — static HTML site
4. Deploy!
